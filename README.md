# Obywatelstwo Trener

Static single-page trainer for the English reading and writing portions of the USCIS naturalization (N-400) test. Polish interface, official USCIS vocabulary lists, audio dictation via the browser's speech synthesis, per-learner progress in localStorage.

No build step. Deploy `index.html` as a static site (Vercel: import the repo, framework preset "Other", leave build settings empty).
